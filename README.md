### Architectural Philosophy & Engineering Focus

I design and build resilient, maintainable, and data-intensive software systems grounded in rigorous computer science fundamentals. My work bridges theoretical algorithmic efficiency with production-grade software engineering:

* **Backend & Distributed Systems:** Designing modular, fault-tolerant RESTful services and concurrent applications adhering to **SOLID principles**, **GoF Design Patterns**, and structured architectural modeling (**UML / C4 Model**).
* **Database Internals & Storage Engines:** Investigating physical data layouts, query execution plans, and indexing trade-offs across relational and NoSQL engines (**B+ Tree, GiST, SP-GiST vs. LSM-Tree**), focusing on read/write amplification, tail latency (p95/p99), and memory footprint.
* **Cloud Native & Reproducible Infrastructure:** Packaging multi-service architectures with **Docker** and **Docker Compose**, enforcing deterministic environments, automated testing, and performance telemetry.
* **Applied AI & Intelligent Pipelines:** Integrating computer vision, machine learning inference, and automated data workflows into scalable backend systems.
